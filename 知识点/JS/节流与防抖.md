| 特性       | 防抖 (Debounce)         | 节流 (Throttle)             |
| -------- | --------------------- | ------------------------- |
| **核心思想** | 频繁触发时，**只执行最后一次**     | 频繁触发时，**按固定频率执行**         |
| **执行时机** | 事件停止触发后，等待一段时间执行      | 在规定的单位时间内至少执行一次           |
| **效果**   | 将多次操作合并为一次            | 保证一段时间内只执行一次              |
| **类比**   | 电梯关门                  | 技能冷却                      |
| **适用场景** | `input` 搜索联想、`resize` | `scroll`、`mousemove`、按钮点击 |
### 一、防抖 (Debounce)

**核心思想**：在事件被触发 n 秒后**再执行**回调函数。如果在这 n 秒内事件又被触发，则**重新计时**。保证只在最后一次操作后执行一次。

```js
function debounce(func, wait) {
  let timeout;
  return function() {
    const context = this;
    const args = arguments;
    // 清除之前的定时器，重新开始计时
    clearTimeout(timeout);
    timeout = setTimeout(() => {
      func.apply(context, args);
    }, wait);
  };
}

// 使用示例
const myInput = document.getElementById('input');
myInput.addEventListener('input', debounce(function(e) {
  console.log('发起搜索请求：', e.target.value);
}, 500)); // 停止输入500ms后才执行
```

### 二、节流 (Throttle)

**核心思想**：规定在一个单位时间内，**只能执行一次**函数回调。如果这个单位时间内事件被多次触发，只有一次生效。保证函数有规律地执行。

```js
function throttle(func, wait) {
  let timeout;
  return function() {
    const context = this;
    const args = arguments;
    if (!timeout) {
      timeout = setTimeout(() => {
        timeout = null;
        func.apply(context, args);
      }, wait);
    }
  };
}
```

伪类（Pseudo-class）和伪元素（Pseudo-element）是CSS中两个不同的概念，它们的核心区别在于**操作的对象和目的**。

---

### 核心区别总结

| 特性       | 伪类 (Pseudo-class)                   | 伪元素 (Pseudo-element)                  |
| -------- | ----------------------------------- | ------------------------------------- |
| **作用对象** | **已有的元素**的**特定状态**                  | 创建并样式化**原本不存在的元素**（虚拟元素）              |
| **目的**   | 为元素在**特定状态**下应用样式                   | 为元素添加**额外的装饰性或结构性的内容**                |
| **语法**   | 单冒号 (`:`)                           | 双冒号 (`::`) **（CSS3规范）**               |
| **例子**   | `:hover`, `:active`, `:first-child` | `::before`, `::after`, `::first-line` |

**简单比喻：**

- **伪类**：就像给一个已经存在的人加上不同的状态标签，比如“忙碌中”、“休假中”，然后根据这个状态来改变他的装扮。
    
- **伪元素**：就像是无中生有地给这个人添加一些原本没有的东西，比如“戴上一顶帽子”或“拿上一根手杖”。
    

---

### 一、伪类 (Pseudo-classes)

伪类用于选择处于**特定状态**或满足**特定条件**的元素。这个元素已经存在于DOM树中。

#### 常见伪类别表：

1. **用户行为状态**：
    
    - `:hover` - 鼠标悬停在元素上时的状态。
        
    - `:active` - 元素被激活（如鼠标点击）时的状态。
        
    - `:focus` - 元素获得焦点（如表单输入框）时的状态。
        
    - `:visited` - 已访问过的链接状态。
        
2. **结构相关状态**：
    
    - `:first-child` - 选择是其父元素的**第一个子元素**的元素。
        
    - `:last-child` - 选择是其父元素的**最后一个子元素**的元素。
        
    - `:nth-child(n)` - 选择是其父元素的第**n**个子元素。
        
    - `:not(selector)` - 选择**不匹配**给定选择器的元素。
        
    - `:checked` - 被选中的单选按钮（radio）或复选框（checkbox）。
        

#### 示例代码：

```css
/* 当鼠标悬停在按钮上时，改变背景色 */
button:hover {
  background-color: lightblue;
}

/* 列表的第一项文字变为红色 */
ul li:first-child {
  color: red;
}

/* 所有不是最后一个子元素的列表项添加右边距 */
ul li:not(:last-child) {
  margin-right: 10px;
}
```


---

### 二、伪元素 (Pseudo-elements)

伪元素用于创建并样式化一些**不在原始DOM文档树中的元素**。它们就像是凭空插入了一个虚拟的元素。

#### 常见伪元素列表：

1. `::before` - 在元素**内容之前**插入一个虚拟元素。
    
2. `::after` - 在元素**内容之后**插入一个虚拟元素。
    
3. `::first-line` - 选择元素内容的**第一行**（只能用于块级元素）。
    
4. `::first-letter` - 选择元素内容的**第一个字母**（常用于首字母下沉效果）。
    
5. `::selection` - 改变用户**选中文本**后的背景和文字颜色。
    

**⚠️ 关于语法 (`:` vs `::`)：**

- 在CSS2中，伪元素和伪类都使用单冒号 (`:`)。
    
- **CSS3规范为了明确区分两者，规定伪元素使用双冒号 (`::`)**。
    
- 但为了向后兼容，浏览器仍然支持单冒号的伪元素写法（如 `:before`）。
    
- **在实际开发中，建议遵循CSS3规范，使用 `::` 来表示伪元素**，这是一个良好的习惯。
    

#### 示例代码：

```css
/* 在每个 <h1> 标题前添加一个装饰性的引号 */
h1::before {
  content: "“"; /* content属性是必须的，即使为空 */
  color: #ff0000;
}

/* 在每个链接后添加一个（外部链接）的提示符 */
a[href^="http"]::after {
  content: " ↗";
}

/* 实现首字母下沉效果 */
p::first-letter {
  font-size: 2em;
  float: left;
  line-height: 1;
}

/* 改变用户选中文本的样式 */
::selection {
  background-color: yellow;
  color: black;
}
```


---

### 组合使用

伪类和伪元素可以组合在一起使用，实现更精细的控制。

```css
/* 鼠标悬停在按钮上时，在按钮文字后添加一个箭头 */
button:hover::after {
  content: " →";
}

/* 第一个段落的第一个字母下沉 */
p:first-of-type::first-letter {
  font-size: 3em;
}

```

### 总结

|特征|伪类 (`:`)|伪元素 (`::`)|
|---|---|---|
|**核心思想**|**选择状态**|**创建元素**|
|**操作对象**|已存在的元素|虚拟的、新创建的元素|
|**典型应用**|`:hover`, `:checked`, `:first-child`|`::before`, `::after`, `::selection`|
|**关键区别**|定义元素的特殊状态|创建文档语言指定的之外的元素|

记住这个最简单的区分方式：**如果你想为某个特定状态添加样式，用伪类；如果你想添加一些新的内容并为其添加样式，用伪元素。**

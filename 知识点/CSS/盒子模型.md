CSS 盒子模型（Box Model）是前端布局和设计的基石，是所有HTML元素都可以被看作的一个基础抽象模型。它定义了元素如何占据空间，以及如何计算元素的尺寸。

### 核心概念：四个组成部分

每个元素都被表示为一个矩形的盒子，这个盒子由从内到外的四个部分组成：

1. **内容区域 (Content)**：
    
    - 盒子最核心的区域，显示文本、图像或其他实际内容。
        
    - 其尺寸由 `width` 和 `height` 属性设置。
        
2. **内边距 (Padding)**：
    
    - 位于内容区域和外边框之间的透明区域。
        
    - 控制内容与边框之间的间距。
        
    - 其尺寸由 `padding` 系列属性设置。
        
3. **边框 (Border)**：
    
    - 包裹在内边距和内容区域外的边框线。
        
    - 其样式、颜色和粗细由 `border` 系列属性设置。
        
4. **外边距 (Margin)**：
    
    - 盒子最外层的透明区域，用于控制当前元素与其他元素之间的间距。
        
    - 其尺寸由 `margin` 系列属性设置。

### 两种盒子模型：关键区别

这里有一个非常重要的概念：**如何计算盒子的总宽度和总高度**。CSS提供了两种不同的计算模型，由 `box-sizing` 属性控制。

#### 1. 标准盒子模型 (content-box) - 默认值

- **`box-sizing: content-box;`**
    
- **计算方式**：
    
    - **元素的总宽度** = `width` + `padding-left` + `padding-right` + `border-left` + `border-right` + `margin-left` + `margin-right`
        
    - **元素的总高度** = `height` + `padding-top` + `padding-bottom` + `border-top` + `border-bottom` + `margin-top` + `margin-bottom`
        
- **特点**：你设置的 `width` 和 `height` **只代表内容区域的尺寸**。如果你再增加 `padding` 或 `border`，盒子的总宽高会随之增大。
    

#### 2. 怪异盒子模型 (border-box) - 推荐使用

- **`box-sizing: border-box;`**
    
- **计算方式**：
    
    - **元素的总宽度** = `width` + `margin-left` + `margin-right`
        
        - 注意：这里的 `width` 已经包含了 `content` + `padding` + `border`。
            
    - **元素的总高度** = `height` + `margin-top` + `margin-bottom`
        
        - 同理，`height` 已经包含了 `content` + `padding` + `border`。
            
- **特点**：你设置的 `width` 和 `height` **代表了这个盒子可见框的总尺寸（内容+内边距+边框）**。再增加 `padding` 或 `border`，会挤压内容区域的空间，但盒子的总宽高不变。

## 1. 父传子（常见）

###  `props`

- 父组件通过 `props` 向子组件传递数据。
    

`<!-- Parent.vue --> <Child :msg="parentMsg" />  <!-- Child.vue --> <script setup> defineProps({   msg: String }) </script> <template>{{ msg }}</template>`

---

## 2. 子传父

### `emit`

- 子组件通过 `emit` 触发事件，父组件监听。
    

`<!-- Child.vue --> <script setup> const emit = defineEmits(['update']) const sendMsg = () => emit('update', 'hello from child') </script> <template>   <button @click="sendMsg">Send</button> </template>  <!-- Parent.vue --> <Child @update="msg = $event" />`

---

## 3. 父子互传（双向绑定）

###  `v-model`

- Vue3 允许在组件上用 `v-model` 实现双向绑定。
    

`<!-- Parent.vue --> <Child v-model="text" />  <!-- Child.vue --> <script setup> const props = defineProps(['modelValue']) const emit = defineEmits(['update:modelValue']) const update = (e) => emit('update:modelValue', e.target.value) </script> <template>   <input :value="props.modelValue" @input="update" /> </template>`

---

## 4. 兄弟组件

### 事件总线（Vue2 用得多，Vue3 推荐 Pinia）

- Vue2 常用 **事件总线 (EventBus)**，Vue3 官方推荐 **状态管理 (Pinia / Vuex)**。
    

`// eventBus.js import mitt from 'mitt' export const bus = mitt()  // A.vue bus.emit('msg', 'hello')  // B.vue bus.on('msg', data => console.log(data))`

---

## 5. 跨层级（祖孙组件）

###  `provide / inject`

- 父组件 `provide`，子孙组件 `inject`。
    

`<!-- App.vue --> <script setup> import { provide } from 'vue' provide('theme', 'dark') </script>  <!-- DeepChild.vue --> <script setup> import { inject } from 'vue' const theme = inject('theme') </script> <template>{{ theme }}</template>`

---

## 6. 全局状态管理

###  Vuex / Pinia

- 适合中大型应用，解决复杂的跨组件通信。
    

`// store.js (Pinia) import { defineStore } from 'pinia' export const useMainStore = defineStore('main', {   state: () => ({ msg: 'hello' }) })  // A.vue const store = useMainStore() store.msg = 'new'  // B.vue const store = useMainStore() console.log(store.msg) // 'new'`

---

## 7. 其他方式

- **`attrs / listeners`**：父传子时自动透传未定义的 props。
    
- **URL / query / params**：通过路由参数传递。
    
- **localStorage / sessionStorage**：不推荐大量使用，只适合持久化数据。
    

---

**总结**

- 父 → 子：`props`
    
- 子 → 父：`emit`
    
- 父 ↔ 子：`v-model`
    
- 兄弟：事件总线 / Pinia
    
- 跨层级：`provide / inject`
    
- 全局共享：Vuex / Pinia

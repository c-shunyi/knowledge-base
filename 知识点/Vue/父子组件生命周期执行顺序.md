### 🟢 挂载阶段（父 → 子 → 父）

1. **父 setup / beforeCreate**
    
2. **父 created**
    
3. **父 beforeMount**
    
4. **子 setup / beforeCreate**
    
5. **子 created**
    
6. **子 beforeMount**
    
7. **子 mounted**
    
8. **父 mounted**
    

⚠️ 在 Vue 3 中，`setup` 会在 `beforeCreate` 之前执行。

## 🔴 销毁阶段（父 → 子 → 父）

如果父组件销毁了子组件：

1. **父 beforeUnmount (beforeDestroy in Vue2)**
    
2. **子 beforeUnmount**
    
3. **子 unmounted (destroyed in Vue2)**
    
4. **父 unmounted**

## 🟡更新阶段（父更新引起子更新）

当父组件的响应式数据变化 → 触发重新渲染：

1. **父 beforeUpdate**
    
2. **子 beforeUpdate**
    
3. **子 updated**
    
4. **父 updated**

## 🔑 总结

- **挂载时**：父组件先创建，再到子组件挂载，最后父组件 mounted。
    
- **更新时**：父 beforeUpdate → 子 updated → 父 updated。
    
- **销毁时**：父触发销毁 → 子销毁 → 父销毁。

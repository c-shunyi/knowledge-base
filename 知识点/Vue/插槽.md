
| 类型    | 子组件写法                         | 父组件写法                                              | 说明             |
| ----- | ----------------------------- | -------------------------------------------------- | -------------- |
| 默认插槽  | `<slot>默认内容</slot>`           | `<Child>内容</Child>`                                | 父组件不传显示默认内容    |
| 具名插槽  | `<slot name="header"></slot>` | `<template #header>内容</template>`                  | 多个插槽，用 name 区分 |
| 作用域插槽 | `<slot :item="item"></slot>`  | `<Child v-slot="{ item }">{{ item.name }}</Child>` | 父组件可使用子组件传出的数据 |
## **基本插槽（默认插槽）**

### 子组件

```vue
<template>
	<div class="card">
		<slot>默认内容</slot>
	</div>
</template>
```

### 父组件

```vue
<Card>   
	<p>这是插入的内容</p> 
</Card>`
```

✅ **说明**：

- `<slot>` 内的内容是默认内容，当父组件没有提供内容时显示。

## **3. 具名插槽（Named Slot）**

### 子组件

```vue
<template>   
	<div class="card">     
		<header>
			<slot name="header">默认标题</slot>
		</header>     
		<main>
			<slot>默认内容</slot>
		</main>     
		<footer>
			<slot name="footer">默认底部</slot>
		</footer>   
	</div> 
</template>`
```

### 父组件

```vue
<Card>   
	<template #header>     
		<h1>自定义标题</h1>   
	</template>    
	<p>自定义内容</p>    
	<template #footer>     
		<small>自定义底部</small>   
	</template> 
</Card>`
```

✅ **说明**：

- `#header` 是 `v-slot:header` 的简写。
    
- 默认插槽仍然可以使用 `<slot>` 填充。
    

---

## **4. 作用域插槽 / 具名作用域插槽（Scoped Slot）**

父组件不仅能传模板，还能 **接收子组件传出的数据**。

### 子组件

```vue
<template>   
	<ul>     
		<li v-for="item in items" :key="item.id">       
			<slot :item="item">{{ item.name }}</slot>     
		</li>   
	</ul> 
</template>  

<script setup>
const items = [   { id: 1, name: 'A' },   { id: 2, name: 'B' } ] 
</script>
```

### 父组件

```vue
<MyList v-slot="{ item }">   
	<strong>{{ item.name }}</strong> 
</MyList>
```

✅ **说明**：

- `v-slot="{ item }"` 是解构子组件传出的作用域数据。
    
- 作用域插槽让父组件可以灵活渲染子组件数据。
